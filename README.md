# PhysicalChess

턴 없이 실시간으로 겨루는 1:1 체스 게임. Google Play 배포가 목표다.

## 컨셉

- **극한의 피지컬 싸움**: 반응속도와 순간 판단력으로 승부가 갈린다. 승부욕을 최대치로 끌어올리는 것이 목표다.
- **턴이 없다**: 두 플레이어가 동시에, 원할 때 말을 움직인다.
- **말은 스킬샷처럼 날아간다**: 예를 들어 비숍은 대각선을 따라 시간을 들여 이동한다. "말을 누르고 칸을 누르는" 방식은 쓰지 않는다.
- **이동 중 방향 전환**: 날아가는 말을 잡아서 적절한 타이밍에 다른 곳을 터치하면 도중에 방향을 바꿀 수 있다.

## 정해진 것

| 항목 | 결정 |
|---|---|
| 인원 | 1:1 온라인 대전 |
| 플랫폼 | 모바일(폰, 태블릿), Android 우선 |
| 판정 | 서버가 모든 판정을 확정한다 |
| 랭크 게임 | 단판승, 끝난 뒤 리매치 신청 가능 |
| 프로 리그(생긴다면) | 3판 2선승 또는 5판 3선승 |
| 한 판 최대 시간 | 3분 (시제품에서 조정할 수 있게 설정값으로 둔다) |

## 아직 정하지 않은 것

- **방향 전환 지점**: 아무 위치에서나 꺾을 수 있는지, 칸 중앙을 지날 때만인지
- **전환 후 이동 규칙**: 꺾은 뒤에도 그 말의 원래 이동 규칙(비숍은 대각선)을 따르는지
- **충돌 결과**: 움직이는 말끼리 만났을 때 어떻게 되는지
- **이동 제한**: 쿨다운을 두는지, 둔다면 말마다인지 전체인지
- **동시 조작**: 여러 손가락으로 여러 말을 한꺼번에 움직일 수 있는지
- **승리 조건**: 킹을 잡으면 이기는지
- **시간 초과 시 승패**: 남은 말의 가치로 정할지, 연장전으로 갈지
- **리매치 제한**: 연속 횟수 제한과 랭크 점수 반영 방식
- **화면 표현**: 위에서 내려다보는 고정 시점이 유력하다
- **개발 도구**: 컨셉이 확정되면 정한다. 지금 저장소의 Unreal Engine 5.4.4 템플릿은 확정이 아니다
